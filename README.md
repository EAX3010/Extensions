# Extensions Library

This is a utility library I built to help with high-performance server applications. I originally made it using .NET Framework 4.0 

## What's in here?

I've included a bunch of useful stuff that I've found helpful when building servers that need to handle lots of concurrent operations:

- Thread management tools (ThreadGroup, ThreadBase)
- Timing utilities (Time32, Timer, etc.)
- Thread-safe collections (SafeDictionary)
- Some randomization utilities
- Event subscription system
- Various concurrency helpers
